# Realistic draft classes

One file per draft year: `2027.json`, `2028.json`, `2029.json` (the years are listed in `js/realclasses.js`).

A file is a Draft Class Lab export (Export Class), or any JSON holding a list of prospects in the save's player
format. With "Realistic draft classes" on (the realistic NBA setup, or Settings → Basics), the class replaces the
game's own when a save reaches that offseason, before the draft, once per save. Each save gets a slightly varied copy:
ratings, tendencies and personality move a little, and a few potentials swap a step in pairs, so the number of players
at every potential stays the same.
